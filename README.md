# Social Focus — product development stopped

**Decision: NO-GO for the revised original-native-iPhone-app requirement under the stated constraints.** The feasibility review is complete; no completed native blocker or successful native proof of concept is claimed.

The required product must block Instagram Reels, Stories and Explore, and TikTok consumption destinations, **inside the official iPhone apps**, while keeping native DMs, profiles, settings and posting/previews usable. Browser products, whole-app locks, Android accessibility techniques, private APIs, modified binaries and additional spending are excluded.

Read the [evidence-based native feasibility decision](docs/NATIVE_APP_FEASIBILITY.md), [revised scope](docs/SCOPE.md) and [current progress](PROGRESS.md). Sources were checked on 2026-10-20. The review explicitly includes current Apple Screen Time APIs, iOS 26 URL filtering, accessibility/automation, Guided Access, SocialLite's iPhone claims and pinned implementation source.
