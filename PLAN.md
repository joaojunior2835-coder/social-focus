# Build order
1. Verify account/write/workflow access, public runner costs and personal signing documentation.
2. Build device-target SwiftUI/WKWebView shell and separate Safari target without restricted entitlements.
3. Implement shared classifier, guards, document-start CSS, batched DOM filtering, SPA handling and settings.
4. Execute unit and real Chromium extension fixture tests in GitHub Actions; fix regressions.
5. Package unsigned IPAs and Chromium ZIP with source SHA/checksums.
6. Validate live authenticated features and physical iPhone install/refresh. These cannot be replaced with fixtures.
