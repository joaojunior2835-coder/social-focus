# Revised scope — 2026-10-20
The user's mission change supersedes the prior browser-first mission.

Only accepted product: selective consumption blocking inside original Instagram/TikTok iPhone apps, keeping native DMs, ordinary profiles/settings and posting with previews usable, surviving reopen.

Constraints: non-jailbroken iPhone; supported public APIs; no modified app binaries, private APIs, bypasses, credential interception, paid membership, required App Store submission or extra spending. GitHub remains the durable source.

Rejected substitutes: browsers/extensions/PWAs/replacement apps, Android-only services, whole-app blocks, reminders, initial DM deep links that leave feeds accessible, blanket video traffic blocking.

Build order: evidence-based native feasibility decision first. Only a credible supported candidate permits the smallest targeted POC. Any real-device tests remain explicitly pending; unavailable tools/phone are not evidence of impossibility. A justified NO-GO means stop product development, preserve the repository and explain the exact unmet requirement. Do not ask for device details absent a concrete compatibility/test need.
